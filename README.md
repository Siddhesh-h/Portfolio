# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, experience, and contact information. The portfolio features a clean UI, smooth animations, dark/light theme support, project highlights, and an integrated contact form.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Dark and Light theme toggle
- Interactive hero section with animated text
- About section with professional background and goals
- Skills section with progress indicators
- Featured projects showcase
- Contact form powered by EmailJS
- Toast notifications for form submissions
- Smooth hover animations and glassmorphism-inspired UI
- Downloadable resume

## Sections

- Home
- About Me
- Skills & Technologies
- Featured Projects
- Contact

## Technologies Used

### Frontend

- React.js

- JavaScript (ES6+)

### Libraries & Tools

- React Icons

## Installation

Clone the repository:

```bash
git clone https://github.com/Siddhesh-h/Portfolio.git
```

Navigate to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the root directory:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

Start the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
